博客灾难恢复：从部署产物里抢救Hexo站点

2026-11-27
技术分享
Word count: 1.3k   |   Reading time≈ 5 min

记一次真实的灾难恢复：WSL 系统重置把博客源目录 ~/hexo/blog 抹掉了，只留下两个压缩包——一份较旧的源码备份和一个 GitHub Pages 部署产物的 master 分支 zip。这次恢复的收获是：部署产物本身就是最完整、最新的”备份”，只要会做逆向，源码是可以拼回来的。

1. 盘点残骸

对照 zip 里旧源码的 source/_posts/*.md：52 篇。差集一跑，3 篇只在部署产物里存在的 2026 年新文章立刻现形——就是丢的那部分：

另外还发现 2 个只有几百字节的”Redirecting…”页面——是改标题前的旧链接留下的重定向桩，canonical 指向新 slug，这个线索也顺手还原了文章改名的历史。

.deploy_git 里的 git log 也值得看：Site updated: 提交时间线直接告诉你最后一次部署是什么时候、中途有没有断档。

2. HTML 逆向回 Markdown

部署页是 Hexo 渲染管线”最下游”的产物，往回走要过三关：正文容器定位、代码块还原、frontmatter 重建。

Ayue 主题正文在 div.article-entry 里；代码块是 hexo-highlight 的经典样式——figure.highlight 里嵌一个 gutter/code 双列表格，行号在 td.gutter，代码在 td.code 的 span.line 里，每行一个 span。还原核心：

要点：

  • 先做 DOM 预处理再交给 markdownify：删掉 <a class="headerlink"> 锚点、figure 换围栏代码、<video> 标签原样保留（Hexo 的 markdown 渲染器对原始 HTML 是透传的，复盘里的演示视频就是这么找回来的）；
  • frontmatter 从页面元数据重建：h1 是 title，<time datetime="...Z"> 是 date（注意是 UTC，要 +8 转回本地写法），a.article-tag-list-link 和 a.article-category-link 就是 tags/categories；
  • 图片视频从 zip 里解出 images/、videos/ 目录，按正文引用路径放回 source/。

一个有意思的坑：文件名和终端回显里 2026-11-19 和 2026/11/19 两种 permalink 形态反复横跳，最后用 ord() 直接看路径分隔符的码点才确认——部署路径是标准 :year/:month/:day/:title/，是渲染层把日期里的 / 显示成了 -。对字符串显示有怀疑的时候，看码点，别看眼睛。

3. 全站一致性回写

旧源码里 52 篇文章的 tags 是历史上各种手写的样子（Python/python/LLm 混用）。而部署产物里每篇文章页脚的 tag/category 列表才是最后一次构建的真实口径。于是把 54 篇部署页的元数据全部抽成 deployed_meta.json，再按 slug 回写到每篇 md 的 frontmatter——一次”以产物为准”的分类学大扫除，顺带修复了改名文章的旧链接（还原 2 个 redirect 桩 + about/links/tags/categories 独立页面重建 + 补上 hexo-generator-search 的 search.xml）。

4. 验证：和线上产物做文件级 diff

恢复完不能只”能跑”，要和线上逐文件对账：

再加上关键静态资源哈希比对——dist/main.css、main.js、custom.css 与线上字节级一致，说明压缩包里的主题版本就是最后一次部署用的版本，主题修复并没有丢。至此从 56 个部署页反推 55 篇源文章（3 篇逆向重建），全部通过。

5. 局限与教训

  • 逆向出的 3 篇 Markdown 是”内容等价”而非”字符等价”：表格、行内样式等经过 DOM→MD 两轮转换，源码写法与原始 md 有出入；文中图片、视频路径已复原，播放正常。
  • 日期时间从 datetime 属性回推，秒级精度依赖渲染时区假设，好在 permalink 只到天，不影响链接。
  • 教训：_posts 源码目录要进 git（只提交 source + 配置，node_modules/public 忽略）。部署产物 zip 能救急，但救回来的是”网站”，不是”工程”。这次靠两份压缩包做到 0 missing，下次别赌运气。

环境：WSL2 Ubuntu 24.04 / Hexo 7.3 / ayue 主题 / Python 3.12 + BeautifulSoup + markdownify。全程未动线上一个字节，直到 diff 归零才 hexo deploy。
